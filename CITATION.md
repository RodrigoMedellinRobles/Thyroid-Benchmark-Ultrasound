# Citing this work

This code accompanies a research paper. Every dataset it evaluates is public,
and the code is MIT licensed so the benchmark can be re-run, extended and
disputed freely.

If you use this code, or results produced with it, please cite the paper. See
[`CITATION.cff`](CITATION.cff) for the machine-readable record.

The four datasets carry their own licences and data use agreements, two of them
requiring an access request. Nothing here redistributes any of them, and the MIT
licence grants you no rights to the data; honour each dataset's terms separately.
